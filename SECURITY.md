# Security Policy

Only the latest version of `unfollowz` is currently supported with security updates.

| Version | Supported |
| ------- | ---------- |
| Latest  | ✅ |
| Older versions | ❌ |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please open a GitHub issue with details about the problem and steps to reproduce it.

Please avoid sharing sensitive information publicly if the issue could impact users' privacy or security.<br>
I will review reports as soon as possible and work on a fix if the vulnerability is confirmed.<br>
